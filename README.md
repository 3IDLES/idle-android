## 🚩 Android Tech Stack

### Architecture

- CleanArchitecture
- Multi-Module
- MVVM

### UI

- Compose
- xml + Databinding
- Coil
- Naver Map SDK

### Data

- Retrofit2 + Okhttp3 + KotlinxSerilization
- Datastore

### Logging

- Amplitude
- Firebase (Crashlytics, Analytics)

### CI/CD

- Firebase (App Distribution, Test Lab)

### Test

- KtLint, junit, mockk

### Etc

- Coroutine + Flow
- Custom Plugin
- Firebase (RemoteConfig, Cloud Messaging)
- Daum Address API - [Github.io 배포를 이용하여 웹뷰 뛰움](https://github.com/tgyuuAn/DaumAddressApi)
- Kakao Shared
- AppsFlyer (Onelink)
